Workspace Access Control

Controls membership, invitations, and high-level roles that govern visibility and actions across Spaces and Projects within a workspace.

Overview

  • Goal: Ensure only authorized users can access a workspace and perform workspace-level actions.
  • Membership lifecycle: invite → accept (by invitation_id) → change role → remove/leave → transfer ownership.
  • Roles: Owner, Admin, Member; define who can manage members, settings, and billing (if applicable).
  • Security: Invitations are bound to invite_id (UUID). Acceptance requires authenticated user email to match the invite.
  • Discoverability: Workspaces are private to members; optional invite codes enable controlled self-join.
  • Auditing: Track invitations, acceptances, role changes, and removals for traceability.
  • Non-goals: Workspace-wide public read access is not supported.

Backend

Data Model

  • Tables: workspace, workspace_member, role. (TODO: add diagram)
  • Relationships: user → workspace_member (role), ownership transfer constraints.

APIs

  • Invite member, accept invite, list/remove members, change roles.
  • Handlers and flow documented in appflowy-backend/doc/WORKSPACE_INVITATION_FLOW.md.

Endpoint inventory (see appflowy-backend/API_ENDPOINTS_DOCUMENTATION.md §10–11 and doc/WORKSPACE_INVITATION_FLOW.md):

  • GET /api/workspace/{workspace_id}/member — List members
  • POST /api/workspace/{workspace_id}/member — Update member (role)
  • DELETE /api/workspace/{workspace_id}/member/{member_id} — Remove member
  • PUT /api/workspace/{workspace_id}/member/{member_id}/role — Update role
  • POST /api/workspace/{workspace_id}/invite — Create invitation
  • GET /api/workspace/{workspace_id}/invitations — List invitations
  • GET /api/workspace/invite — Get my invitations
  • GET /api/workspace/invite/{invite_id} — Get invitation details
  • POST /api/workspace/accept-invite/{invite_id} — Accept invitation
  • POST /api/workspace/join-by-invite-code — Join by invite code
  • GET/POST/DELETE /api/workspace/{workspace_id}/invite-code — Get/Generate/Delete invite code

Example payloads (illustrative):

// Invite workspace members (array supported via DTO in flow doc)
POST /api/workspace/{workspace_id}/invite
[
  { "email": "user1@example.com", "role": "Member" },
  { "email": "user2@example.com", "role": "Guest", "skip_email_send": false }
]

// Accept invitation
POST /api/workspace/accept-invite/{invite_id}
{}

// Change role
PUT /api/workspace/{workspace_id}/member/{member_id}/role
{ "role": "Owner" }

Standard response envelope: see appflowy-backend/API_ENDPOINTS_DOCUMENTATION.md.
