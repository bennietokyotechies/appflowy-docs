Authentication — OAuth Providers

This guide helps developers enable and test OAuth-based authentication (Google, GitHub, Discord) during onboarding. AppFlowy uses GoTrue for identity and an AppFlowy Cloud layer for user sync and authorization.

Architecture: GoTrue manages identity (OAuth, JWT), while AppFlowy Cloud syncs authenticated users to af_user and handles workspaces/permissions. See Authentication Architecture.

Prerequisites

  • Backend stack running (see Environment Setup)
  • Valid .env in appflowy-backend/ generated by ./script/generate_env.sh
  • Frontend (web) running on http://localhost:3000 or your chosen domain

Key Environment Variables (GoTrue)

# GoTrue base URL and site URL
APPFLOWY_GOTRUE_BASE_URL=http://localhost:9999
GOTRUE_SITE_URL=http://localhost:3000

# JWT must match between GoTrue and AppFlowy
GOTRUE_JWT_SECRET=your_jwt_secret
APPFLOWY_GOTRUE_JWT_SECRET=your_jwt_secret

# Enable providers and set credentials
GOTRUE_EXTERNAL_GOOGLE_ENABLED=true
GOTRUE_EXTERNAL_GOOGLE_CLIENT_ID=your_google_client_id
GOTRUE_EXTERNAL_GOOGLE_SECRET=your_google_client_secret

GOTRUE_EXTERNAL_GITHUB_ENABLED=true
GOTRUE_EXTERNAL_GITHUB_CLIENT_ID=your_github_client_id
GOTRUE_EXTERNAL_GITHUB_SECRET=your_github_client_secret

GOTRUE_EXTERNAL_DISCORD_ENABLED=true
GOTRUE_EXTERNAL_DISCORD_CLIENT_ID=your_discord_client_id
GOTRUE_EXTERNAL_DISCORD_SECRET=your_discord_client_secret

Redirect URI rule: For each provider, authorize the callback https://<your_host>/gotrue/callback (or http://localhost/gotrue/callback for local). Configure this in the provider console and ensure the same domain is used by your frontend.

Provider Setup

Google

  1. Create OAuth Client (Web Application) in Google Cloud Console.
  2. Add Authorized redirect URI: http://localhost/gotrue/callback (or your domain).
  3. Copy Client ID/Secret into your .env (see variables above).

Reference: appflowy-backend/doc/AUTHENTICATION.md

GitHub

  1. Register an OAuth App in GitHub Developer Settings.
  2. Authorization callback URL: http://localhost/gotrue/callback (or your domain).
  3. Copy Client ID/Secret to .env.

Reference: appflowy-backend/doc/AUTHENTICATION.md

Discord

  1. Create a new application in Discord Developer Portal.
  2. Add Redirect: http://localhost/gotrue/callback (or your domain).
  3. Copy Client ID/Secret to .env.

Reference: appflowy-backend/doc/AUTHENTICATION.md

Local Testing

  1. Start backend: ./script/run_local_server.sh (or docker compose -f docker-compose-dev.yml up -d)
  2. Start frontend: pnpm run dev
  3. Sign in with your configured provider. On first login, AppFlowy will create a corresponding af_user record.

Troubleshooting

  • 401 Unauthorized: Ensure GOTRUE_JWT_SECRET equals APPFLOWY_GOTRUE_JWT_SECRET.
  • User not found in af_user: Re-auth to trigger sync; verify backend logs and DB connectivity. See AUTHENTICATION_ARCHITECTURE.md.
  • OAuth callback error: Confirm redirect URI matches exactly in provider console and your site URL.
