Mail Notifications

Server‑generated emails sent via SMTP with handlebars HTML templates. This page documents the current implementation and operations guidance.

Business Overview

  • Purpose: Notify users of critical events even when offline.
  • Scope: Workspace invites/access requests, content mentions; Space/Project events behind feature flags.
  • Reliability: SMTP with retries and error logging; batching for high‑volume events (e.g., mentions).

Features

  • Templated emails using Handlebars under appflowy-backend/assets/mailer_templates/build_production/.
  • Configurable SMTP via environment variables; provider agnostic.
  • Background worker batching for page mentions; grace period to reduce noise.
  • Links back to Web app using APPFLOWY_WEB_URL.

Implemented Emails

  • Workspace
    • Invitation — AFCloudMailer::send_workspace_invite → workspace_invitation.html
    • Access Request — send_workspace_access_request → access_request.html
    • Access Request Approved — send_workspace_access_request_approval_notification → access_request_approved_notification.html
  • Content
    • Page Mention — send_page_mention_notification → page_mention_notification.html (batched)
  • Space (feature‑gated)
    • Invitation — send_space_invitation → space_invitation.html
    • Role Update — send_space_role_update → space_role_update.html
    • Member Removal — send_space_member_removal → space_member_removal.html
  • Project (feature‑gated)
    • Invitation — send_project_invitation → project_invitation.html
    • Role Update — send_project_role_update → project_role_update.html
    • Member Removal — send_project_member_removal → project_member_removal.html
  • Auth (GoTrue service) — confirmation, recovery, magic link via GoTrue SMTP.

Configuration

  • SMTP: APPFLOWY_MAILER_SMTP_HOST, APPFLOWY_MAILER_SMTP_PORT, APPFLOWY_MAILER_SMTP_USERNAME, APPFLOWY_MAILER_SMTP_EMAIL, APPFLOWY_MAILER_SMTP_PASSWORD, APPFLOWY_MAILER_SMTP_TLS_KIND
  • Notifications: APPFLOWY_NOTIFICATION_ENABLE_EMAIL, APPFLOWY_NOTIFICATION_EMAIL_INTERVAL_SECS, APPFLOWY_NOTIFICATION_EMAIL_GRACE_PERIOD_SECS
  • App URL: APPFLOWY_WEB_URL (for accept/join links)

Testing

  • Unit: template rendering, parameter validation, config parsing.
  • Integration: invite/access/mention flows send expected emails; feature flags gating.

Troubleshooting

  • SMTP auth/TLS errors: verify APPFLOWY_MAILER_SMTP_* and provider settings.
  • No emails locally: ensure Mailpit is running and env points to localhost:1025.
  • Broken links: set APPFLOWY_WEB_URL correctly.
