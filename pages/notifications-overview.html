Notifications — Overview

This page provides a business-focused overview of AppFlowy's notification system and links to detailed pages for each delivery channel.

Business Goals

  • Keep users informed about relevant events such as invitations, approvals, mentions, and role changes.
  • Respect user preferences and reduce noise with batching and opt-in/opt-out controls (planned).
  • Secure by default: notify only authorized recipients and avoid data leakage.

Channels

  • Mail Notifications — Implemented via SMTP using templated emails.
  • In-App Notifications — Planned: real-time delivery with optional persistence.

Status

  • Email: Implemented for workspace invites/access requests, content mentions; Space/Project events feature-gated.
  • In-App: WebSocket transport exists; storage/APIs and UI flows planned.
